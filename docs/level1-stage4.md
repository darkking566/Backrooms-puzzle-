## 已完成

- 同一局穿過真閃爍牆，保留數值、背包、傷勢、時間與隨機流，不觸發結算。
- 目前層級繼續使用 `run.pos/world/map/mapMarks`；舊地圖與記號存進 `mapPages`，Level 1 狀態集中在 `run.l1`。沒有 `run.levels`。

- 入口應急箱、側閂箱謎題與跨局解法記憶、一般搜索、較常見的撬棍。
- Base Alpha 的休息、理智恢復、一次應急配給；已領取的物品與箱子狀態會保存。
- 預設開啟且可手動關閉的手電筒。Level 0 的預設行為不變。

- 雙語內容、靜音字幕、Level 1 的低理智熟悉感／時間錯覺，不生成假鋼琴或假實體。
- 死亡時按層計算存活分與顯示死亡敘述，抵達獎勵延至局末結算。

每階段提交前均通過 `npx tsc --noEmit` 與 `npx vitest run`。第四階段另通過 `npm run build`。

原有 Level 0 BOT 種子 1000～1299，每局全新 Meta、4000 行動上限；抽象化前的逐種子資料保存在 `tests/fixtures/level0-bot.json`，不以改寫基準檔通過回歸。

第四階段保留原 Level 0 決策與抽樣順序。未抵達 Level 1 的局仍比對完整摘要；抵達者比對種子、出口及精確切層分鐘。結果仍為 156 局抵達、95 局渴死、11 局抵達 Level 72、18 局墜落死亡、3 局傷重、17 局在上限仍存活；觀察時間中位數 59 小時，P10／P90 為 37／81。

正式建置以 Chromium 在 `vite preview` 驗證：桌機 1365×900、英文手機 390×844，實際點擊閃爍牆切層；確認時間、數值、背包與 RNG 沒有改變，沒有進結算。另檢查入口取水、手電筒開關、重載保存、舊地圖頁唯讀、基地補給重複領取防護、雙語切換及實際啟用 Web Audio。頁面／WebGL 執行錯誤為零，手機頁寬及內容寬均為 390px。

雲端 Chromium 對既有 Google Fonts 請求出現 `ERR_CERT_AUTHORITY_INVALID`，上述檢查使用系統替代字型；未更動原有字型來源或略過 TLS 驗證。

抵達者再以獨立的倉庫策略最多操作 500 次：先找基地、飲水進食、疲勞時回基地睡眠、尋找並開啟補給箱。此策略會讀取真實路網與箱子位置，不代表新玩家的找路能力。
